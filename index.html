Principais comandos do Git

Guia rápido para iniciar, versionar e colaborar em projetos.

Inicialização

git init

Cria um repositório Git vazio na pasta atual.

git clone <url>

Baixa uma cópia de um repositório remoto para o seu computador.

Configuração

git config --global user.name "Seu Nome"

Define o nome que aparecerá nos commits.

git config --global user.email "seu@email.com"

Define o e-mail associado aos commits.

Trabalhando com arquivos

git status

Mostra o estado atual dos arquivos do repositório.

git add <arquivo>

Adiciona arquivos modificados à área de staging.

git add .

Adiciona todas as alterações da pasta atual para o staging.

Commit

git commit -m "Mensagem do commit"

Salva as alterações do staging com uma mensagem descritiva.

git log

Exibe o histórico de commits do projeto.

Ramificações

git branch

Lista todas as branches do repositório.

git checkout -b nome-da-branch

Cria e muda para uma nova branch.

git checkout nome-da-branch

Troca para uma branch existente.

Sincronização

git pull

Busca e integra alterações do repositório remoto na branch atual.

git push origin nome-da-branch

Envia commits locais para o repositório remoto.

Mesclagem e atualização

git merge nome-da-branch

Une alterações de outra branch na branch atual.

git reset --hard HEAD

Descarta todas as alterações locais e volta ao último commit.

Repositórios remotos

git remote -v

Mostra os repositórios remotos configurados.

git remote add origin <url>

Associa o repositório local a um repositório remoto.

Dica: use git status com frequência para acompanhar o que foi alterado e garantir que a branch e os commits estejam corretos antes de enviar o código.
