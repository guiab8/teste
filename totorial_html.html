1. Estrutura básica

Todo documento HTML normalmente começa com estas tags:

<!DOCTYPE html>
<html lang="pt-BR">
	<head> ... </head>
	<body> ... </body>
</html>

<head> contém informações da página, enquanto <body> contém o conteúdo visível.

2. Títulos e textos

Este é um subtítulo

Use <h1> até <h6> para títulos e <p> para parágrafos.

Também é possível usar negrito, itálico e
quebra de linha com <br>.
